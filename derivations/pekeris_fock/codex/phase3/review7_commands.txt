Energy code integrates a single exported state, with no dense Ritz matrices or
atom caches. Atom evaluation uses this code's distance formulas and ForwardDiff;
radial integration uses this code's Gamma/log moments. N4 and N8 only.
The a21 Gauss nodes originate in a Float64 symmetric eigensolver; this limits
its numerical agreement to roughly 1e-14 despite BigFloat arithmetic thereafter.
The Julia dependency emits an OpenSpecFun import warning; jobs exit zero.
